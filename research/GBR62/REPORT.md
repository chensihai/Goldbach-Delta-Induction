# GB-R62：無窮多個完整 Goldbach 窗口，並保留任意大的必要偏移

日期：2026-10-26。依使用者澄清，本輪研究無窮存在性。下述為已發表無條件定理的推論，不宣稱首創；全稱 Goldbach 與指定 gap=4 的無窮存在性仍保持開放。Astra 已獨立檢查計數、見證匹配與固定間距的量詞。完整分析推導屬紙面證明，Lean 覆蓋範圍另列。

## 精確結論

存在一個固定偶數 d≥6，使對任意自然數 R、X，都存在 p>X，滿足：

1. p、p+d 是全體素數序列中的相鄰奇素數；
2. 對每個整數 0≤j≤d，2p+2j 都是兩個素數之和；
3. 對每個 0≤δ≤R，p+1−δ、p+1+δ 不同時為素數。

可同時要求 p>R+3。因此第 3 項沒有負數或自然數減法截斷問題。第 2 項包括完整窗口 [2p,2(p+d)] 的所有偶數，而非僅中央項。特別地，2p+2 有表示，故其最小對稱偏移是一個有限整數；第 3 項迫使這個最小值大於 R。

亦即，存在固定 k=d/2≥3，在這個固定間距上有無窮多個完整成功窗口，其中心 p+1 的有限最小 δ 無界。d 只被限制在下面的有限集合 D，沒有被識別為 4、8、186 或其他指定值。

## 兩項已知輸入

**Goldbach 例外集。** 令 E(Y) 為不超過 Y、不能表示成兩個素數之和的正偶數個數。[Montgomery–Vaughan，The exceptional set in Goldbach's problem](https://doi.org/10.4064/aa-27-1-353-370)，Acta Arith. 27 (1975)，Theorem 1，第 353 頁，證明存在 η>0，使充分大 Y 滿足

\[
E(Y)\ll Y^{1-\eta}.
\tag{62.1}
\]

原始掃描 [PDF](https://matwbn.icm.edu.pl/ksiazki/aa/aa27/aa27126.pdf) 已下載並目視核對：其第一張雙頁影像右半頁即印刷頁 353，Theorem 1 確為上述無條件冪次節省。原文包含偶數 2 的例外，與只從 4 起計的版本至多相差 1，不影響本證明。下載檔 SHA256：`a06e5db34b85501f75643c354348bee6f69980b337d31680f11af966fd0f2596`。本推導不需要追逐最新數值指數。

**素數聚簇的計數版本。** [Maynard，Dense clusters of primes in subsets](https://doi.org/10.1112/S0010437X16007296)，Compositio Math. 152 (2016)，Theorem 3.4，第 1520 頁。取 m=2、ε=1/12、y=x，先取得固定 K。對任一固定的可容許正斜率 K 個線性式族 F_h，充分大 x 時，

\[
\#\{n\in[x,2x]:\text{至少兩個 }F_h(n)\text{ 為素數}\}
\gg_F \frac{x}{(\log x)^K}.
\tag{62.2}
\]

固定係數與常數項在 x 足夠大後滿足該定理的範圍。這裡需要數量下界；單獨「無窮多次出現小間距」不足以取代 (62.2)。

## 刪除例外時保留同一批見證

先固定非負整數 L、正整數 W 與整數 a≥0，寫 T(n)=Wn+a。設 A(x) 是 [x,2x] 中的某族起點，且其個數至少為 c x/(log x)^K，其中 c>0、K 固定。

若 n 的長度 L 倍增窗口失敗，則存在 j∈{0,…,L}，使

\[
N=2T(n)+2j
\]

是 Goldbach 例外。固定 j 時，n↦2Wn+2a+2j 為單射；所有目標皆不超過

\[
Y(x)=4Wx+2a+2L.
\]

故所有失敗 n 的個數至多

\[
(L+1)E(Y(x))=O_{W,a,L}(x^{1-\eta})
=o\!\left(\frac{x}{(\log x)^K}\right).
\tag{62.3}
\]

從 A(x) 中刪掉這些 n，充分大 x 後仍至少剩 c x/(2(log x)^K) 個。因此，同一個保留下來的 n 同時滿足原有素數聚簇條件與全部 0≤j≤L 的 Goldbach 條件。這不是把兩個互不相關的存在性見證拼在一起。

## 套用 GB-R60 的隔離構造

沿用 [GB-R60](../GBR60/REPORT.md) 的完整構造與符號。K 先固定，令

\[
B=6K!,\quad H=\{0,B,\ldots,(K-1)B\},\quad L=(K-1)B,
\quad D=\{B,2B,\ldots,(K-1)B\}.
\]

這些量全不依賴 R。對每個 R，CRT 給出固定 W_R、0≤a_R<W_R，使 T=W_R n+a_R 滿足：在位置區間 [−R−2,L+R+2] 內，所有不屬於 H 的位置 T+t 都被指定素數整除；當 n 充分大，這些因子全為真因子。線性式 F_h(n)=W_R n+a_R+h 可容許。

應用 (62.2)、(62.3)，對每個固定 R，都有任意大的 n，同時滿足：

- T+H 中至少兩個位置為素數；
- 全部 0≤j≤L 的 2T+2j 都有 Goldbach 表示；
- GB-R60 指定的所有非 H 位置都是合數。

按大小取 T+H 中前兩個實際素數 p=T+h_i、q=T+h_j。隔離條件保證 p、q 在全體素數中相鄰，且 q−p∈D。其完整窗口中的任一目標可寫成

\[
2p+2s=2T+2(h_i+s),\qquad 0\le s\le q-p,
\]

其中 0≤h_i+s≤h_j≤L，故全部已有表示。

另一方面，若 δ≤R 且 p+1±δ 同時為素數，兩個位置 h_i+1±δ 都落在緩衝區，必須屬於 H；它們的和應被 B 整除，卻等於 2h_i+2≡2 (mod B)，矛盾。這正是 GB-R60 的同餘排除，仍作用在上述同一個 p 上。

每個固定 p 最多來自 K 個不同起點 n（對各 h_i，W_R n+a_R=p−h_i 至多一解），因此無界 n 確實給出無界 p。

## 固定同一個間距，而非隨 R 更換

對每個 R，定義 D_R⊆D：d∈D_R 當且僅當存在任意大的 p，滿足間距 d、完整窗口 Goldbach，以及 δ≤R 全部被排除。上一步和有限鴿巢原理保證 D_R 非空。

這裡 D_R 按實際素數性質定義，沒有把某次 CRT 的餘類限制寫進去。因此 D_{R+1}⊆D_R；即使不同 R 的 CRT 構造不同，這個包含關係仍然成立。

D 是固定有限集，故非空遞減集 D_R 的交集非空。取 d∈⋂_R D_R，便得到開頭的全部量詞。再由 Goldbach 與對稱表示的精確等價式（本專案 `goldbach_iff_symmetric`），中心 p+1 的最小 δ 存在且大於 R。

這補足 GB-R60 原先保留的限制：對此處構造出的完整成功窗口，有限最小偏移的無界性現在不需要另外假設 Goldbach。

## 較直接的推論：幾乎所有相鄰素數窗口都成功

只用 (62.1) 已能證明：p≤X 的相鄰素數窗口中，完整 Goldbach 失敗的窗口至多 E(4X) 個。理由如下。

每個端點 2p、2q 都有自加表示。因此失敗窗口必在開區間 (2p,2q) 中有某個例外偶數。不同相鄰素數窗口的開區間互不相交，從每個失敗窗口選一個例外便得到單射。由 Bertrand 定理，p≤X 時其下一個素數 q<2p≤2X，所選例外小於 4X。故

\[
\#\{p\le X:\text{其完整相鄰窗口失敗}\}
\le E(4X)\ll X^{1-\eta}.
\]

除以 π(X)∼X/log X，失敗比例趨於 0。這首先給出無窮多個完整成功窗口，但不能單靠此比例控制指定間距。上面的 Maynard 計數與 CRT 則把成功窗口保留在同一個固定間距，並同時迫使最小 δ 任意大。

## 對原始目標與 186 的意義

- 原始全稱 Goldbach、每個相鄰窗口都成功，以及 τ≤k 並未由此證明。
- 本結果沒有證明指定 gap=4 的素數對無窮多，也沒有把未知的 cousin-prime 無窮性當作公理。
- 僅假設 gap=4 無窮多次，仍沒有足夠的計數下界來執行本證明的刪除步驟；不能只憑兩個無窮集合就斷言相交。
- 若另外有 gap=4 對數量的下界，例如 ≫X/(log X)^A（A 固定），同一刪除論證便給出無窮多個完整成功的 k=2 窗口。這是條件推論，這項指定間距下界尚未在此建立。
- 186 專案的 liminf≤186 目標本身只有無窮性；本輪沒有審查其分析推導是否還提供適用的計數下界，也沒有以 186 取代本證明的 L。此處使用的是已發表的 Maynard 計數定理。
