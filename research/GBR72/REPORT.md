# GB-R72：實際素數上的全域條件鏈

日期：2026-10-26。本輪將原有紙面歸納骨架接到實際素數定義，核對全部偶數的覆蓋與全稱量詞。這是一般歸納問題的精確接口；一般歸納步仍是明列的待證輸入。

## 1. 固定原目標與完整前提

定義

\[
\begin{aligned}
B(k)&:\ \forall p,\ \operatorname{AdjacentPrimes}(p,p+2k)
\Rightarrow\forall j\le2k,\ G(2(p+j)),\\
\mathrm{GG}&:\ \forall N\ge4,\ N\text{ 偶數}\Rightarrow G(N).
\end{aligned}
\]

其中素數為 mathlib 的 `Nat.Prime`，G 是專案原有 `Goldbach`，沒有更換成抽象集合。B(2) 是完整左右窗口的前提，與專案原有 `B2` 一致，並非只有一個非中央位置的存在性。

需要證明的鏈是

\[
B(0),\ B(1),\ [B(2)]\quad+
\boxed{\ \forall k\ge3,\ (\forall i<k,\ B(i))\Rightarrow B(k)\ }
\quad\Longrightarrow\quad\forall k,\ B(k)
\quad\Longleftrightarrow\quad\mathrm{GG}.
\tag{72.1}
\]

B(0) 因嚴格相鄰而真空成立。B(1) 的全部三個位置分別由兩端自加與中央兩端相加處理。方框仍待證，形式化時必須保留為引理的顯式參數；不得新增同名公理來取代證明。

## 2. 為何全部窗口確實等價於全稱 Goldbach

由 GG 得每個窗口，只需注意其所有目標至少為 4。

反向令 N=2c>=4。c=2 時用 4=2+2；若 c 為素數則 N=c+c。剩下 c>=4 且 c 為合數。取不超過 c 的最大素數 p，以及大於 c 的最小素數 q。

最大 p 的存在由有限集合中至少含 3 得到；最小 q 的存在由 Euclid 的素數無窮性得到。由最大、最小性與 c 非素數，

\[
3\le p<c<q,
\]

且 p、q 真正相鄰。兩者為奇素數，故可寫 q=p+2k。再令 j=c-p，便有 0<j<2k，N=2(p+j)。因此 B(k) 給出 G(N)。不需要任何素數間距的統一上界，也不要求任一指定 k 有無窮多個實例。

## 3. 最小失敗層的精確量詞

假設 B(2)，但 GG 失敗。由第 2 節，失敗層集合 {k:¬B(k)} 非空；取其最小元素 k₀，則

\[
k_0\ge3,\qquad \forall i<k_0,\ B(i),\qquad \neg B(k_0).
\tag{72.2}
\]

因此存在實際相鄰素數 p、p+2k₀ 及 j，使

\[
0<j<2k_0,\quad j\ne k_0,\quad \neg G(2(p+j)).
\tag{72.3}
\]

兩端 j=0、2k₀ 與中央 j=k₀ 不可能失敗，因它們已有端點素數直接表示。

這是從最小失敗得到的全部歸納資訊。它**沒有**附帶「每個較小和值都成功」，也沒有給出任何來源表示的指定加數。GB-R71 的抽象模型說明，僅憑這些集合層面的成功條件不能強迫失敗向較低層傳播；要導出矛盾，仍須實際素數的額外資訊。

## 4. 和值次序與層數次序不能混用

一個具體的算術對照是：中心 120 位於相鄰素數 113、127 之間，層數為 7；中心 132 位於相鄰素數 131、137 之間，層數為 3。因此

\[
240<264,\qquad \operatorname{level}(240)=7>3=\operatorname{level}(264).
\]

研究 k=3 的歸納步時，不能僅因 240<264 就從較低層假設使用 G(240)。反之，276 的中心 138 位於相鄰素數 137、139 之間，層數為 1；所以 G(276) 是合法的低層輸入，雖然 276>264。

此對照的素性、相鄰性及合數中心已用獨立有限試除核對；本文用來解釋量詞，未把這些數值另列為新 Lean 定理，也未加入專案持續驗證範圍。形式化的歸納步對每個 i<k 允許全部 p，沒有附加來源和值上界。

## 5. 對後續橋接引理的要求

有效的新結果應在 (72.2) 的完整較低層資訊下，使用一項實際可證的素數性質，迫使 (72.3) 的目標具有表示。若使用單來源轉移，必須證明來源見證足夠安全；若使用三角重配，必須證明共享加數能共同選取。GB-R70 的局部可容許條件可先篩選來源，但尚未證明這項共同存在性。

本輪整理不將方框內的命題重新命名為已解引理。它的用途是使將來任何候選證明都能直接接到完整 GG，並明確看出尚缺哪一個箭頭。
