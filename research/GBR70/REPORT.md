# GB-R70：條件鏈的來源選擇與完整局部障礙

日期：2026-10-26。沿用使用者接受的完整 B(2) 前提，研究全稱歸納的表示橋接。本輪不增加有限搜尋範圍；將單來源保留加數規則的所有單素數同餘障礙分類。分類能篩選候選來源，仍未證明一般歸納步。

## 1. 已核驗的鏈與一般目標

記 G(N) 為 N 有兩素數表示，B(k) 為每對相鄰奇素數 p、p+2k 的全部偶數目標 [2p,2p+4k] 均滿足 G。

完整研究目標是

\[
[B(2)],\ B(1),\quad
\left[(\forall i<k\ B(i))\Longrightarrow B(k)\right]_{k\ge3}
\quad\Longrightarrow\quad\forall N\ge4\text{ 偶數},\ G(N).
\]

B(1) 由兩端自加與中央兩端相加成立。若每個歸納步成立，全部 B(k) 覆蓋每個合數中心；素數中心本身由自加處理，4=2+2。這個結尾不要求任何指定間距出現無窮次。

目前已有完整核驗的具體條件鏈（GB-R68）：

\[
B(2)\ \Longrightarrow\ G(44)
\ \Longrightarrow\ G(48),G(50),G(54),G(56)
\ \Longrightarrow\ \text{相鄰素數 }23,29\text{ 的完整窗口}.
\]

第一步取 19、23 的窗口；第二步對 44 的全部來源表示逐一成立；其餘 46、52、58 分別由 23+23、23+29、29+29 給出。因此它確實從完整 B(2) 推出一個完整 k=3 窗口，沒有假裝歸納假設可以指定有利的來源表示。它仍只是單個窗口，有限算術也能直接證明。

一般 k 歸納允許使用**和值較大而層數較小**的來源。不能擅自加入 M<N；下文第 4 節特別標明這個額外限制。

## 2. 單來源轉移的局部條件

從來源 M 保留素數 a，欲轉到目標 N，需要

\[
a,\quad M-a,\quad N-a\quad\text{同時為素數}.
\tag{70.1}
\]

對素數模數 ell，三個線性式的零餘類是

\[
a\equiv0,\ M,\ N\pmod{\ell}.
\]

定義「局部可容許」為：對每個素數 ell，都存在一個餘類避開上述三個零餘類。這是一般三線性式的同餘條件，沒有要求某個實際整數使三式均為素數。

對偶數 M、N，有精確等價：

\[
\boxed{\ \text{局部可容許}(M,N)
\ \Longleftrightarrow\
M\equiv0\pmod3\ \lor\ N\equiv0\pmod3\ \lor\ M\equiv N\pmod3.\ }
\tag{70.2}
\]

證明：模 2 取奇數餘類。模 3 唯一失敗情形是 M、N 為互不相同的非零餘類，使 0、M、N 填滿三個餘類。每個素數 ell>=5 至多排除三個餘類，總有剩餘。故這是所有單素數模數的完整分類。

有限多個模數的非零餘類亦可由 CRT 同時選取，但這只得到整數餘類，不保證三個數為素數，也不保證所需區間內有代表元。不同素數對不同候選 a 的覆蓋、實際值的大小及素數相關性仍須另外處理。

## 3. 不可容許時的精確例外

設 M、N 模 3 是互不相同的非零餘類。若素數 a,b,c 滿足

\[
a+b=M,\qquad a+c=N,
\]

則必有

\[
\boxed{a=3\quad\lor\quad b=3\quad\lor\quad c=3.}
\tag{70.3}
\]

否則三者模 3 都非零，而同一個 a 無法同時配出兩種不同的非零和值餘類，矛盾。這不需要 M、N 的偶性。

因此不可容許並非完全排除某次實際轉移：被整除的數可能恰好就是素數 3。在一般有向來源中，成功保留的端點 a 只能位於 {3,M-3,N-3}，其中也須有相應的正值及素性。不能刪掉這些小素數例外。

## 4. 較小和值來源的加強結論

額外假設 6<=M<N，M、N 皆偶數，且仍處於上述不可容許類。若 c=3，則 a=N-3 為奇數，b=M-a<3 亦為奇數，不可能是素數。因此 (70.3) 只剩 a=3 或 b=3：

> 任何成功轉移都必須使用唯一可能的無序來源對 {3,M-3}。

特別地，無論來源總共有多少表示，可轉移的無序來源對至多一組。而且存在成功轉移的精確條件是

\[
\boxed{\ (M-3)\in\mathbb P\quad\land\quad
\bigl((N-3)\in\mathbb P\ \lor\ (N-M+3)\in\mathbb P\bigr).\ }
\tag{70.4}
\]

必要性由上述唯一來源對得出；充分性分別保留 3 或 M-3，即得到 N=3+(N-3) 或 N=(M-3)+(N-M+3)。這個推論只適用 M<N，不能套到按 k 歸納允許的所有來源。

## 5. 尚待建立的箭頭

分類修正來源選擇：可先考慮滿足 (70.2) 的較低層來源；不可容許類則必須明列 (70.3) 的小素數例外。要求 M、N 相差 6 的倍數是充分的局部篩選，但非必要，不能把它當作唯一合法來源。

完成同餘篩選後，仍需證明至少一個合格來源供給可轉移表示，或證明 GB-R67 的多來源共享加數接口。B(i) 僅給出各來源表示集合非空；(70.2) 僅排除固定單素數的完全覆蓋。兩者目前尚未合成所需的共同存在性。

所以一般鏈的未完成部分有明確位置：

\[
\text{較小層表示存在}
\ +\ \text{合法來源的同餘篩選}
\ \xRightarrow{\ \text{待證：至少一組相容表示}\ }
\ G(N).
\]

這個箭頭是數論存在性引理，不能以定義或條件重述充當證明。本輪不聲稱已由 B(2) 推出全部 B(3)，更未閉合全部 k 的歸納。
