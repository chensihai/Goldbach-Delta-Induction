# Goldbach–Delta–Induction

本目錄接續 ChatGPT 對話[「推广哥德巴赫猜想」](https://chatgpt.com/g/g-p-684f7652c29c8191aa64f2eae1cb0787-ge-de-ba-he-cai-xiang/c/6adec5ff-11f8-83ea-8b6e-1121c0d52751)。日期：2026-10-26。

## 研究目標與目前狀態

主目標是證明相鄰奇素數 p<q=p+2k 的完整倍增區間 [2p,2q] 內，每個偶數都有 Goldbach 表示。端點和中央項分別由 p+p、q+q、p+q 保證；其他內部項仍需證明。對所有相鄰奇素數的完整區間結論可涵蓋全部 ≥6 的偶數，4 另由 2+2 處理。

後期研究採用更強的輔助目標：用至多 k 枚不超過 p 的奇素數錨點，覆蓋內部 2k−1 個標籤，即 τ(p,k)≤k。完整覆蓋不自動提供這個成本上界；不能把兩者互換。

**Goldbach 和一般 τ≤k 均未證明。** 本目錄的有限證書和已形式化結論只處理明列的局部或結構性問題。研究目標維持開放。

## 本目錄新增的 Lean 4 結論

- `Basic.lean`：完整內部表示跨越無素數間隙；Goldbach 與左側錨點存在性等價；偶數目標可嚴格排除錨點 2；中央項的無條件表示。
- `PeriodicCapacity.lean`：任意長度 M 的連續整數區間實現每個模 M 的類；週期函數在整個週期放入區間後，局部容量界與全部剩餘類容量界等價。
- `SieveCapacity.lean`：篩除保留 n=ℓ 的小素數例外；當補數大於所有篩素數時，除數形式與模數形式完全一致；實際素數補數通篩；從有限模數定義直接證明容量的週期性，並將上述等價式實例化。
- `IntervalResidues.lean`：任意整數區間中的單一剩餘類數量，與「區間長度／模數」之差嚴格小於 1，包含端點和空區間。
- `DeltaGap.lean`：對稱 δ 表示與 Goldbach 的精確對應；對相鄰素數間的第 j 個中心，證明 δ≥max(j,2k−j)，故非中央項必有 δ>k；中央最小偏移恰為 k。
- `OffsetFactorCertificate.lean`、`OffsetRadiusExamples.lean`：以真因子證書核驗六個精確最小偏移，排除若干固定短半徑界；不聲稱偏移／間隙比值無界。
- `RadiusConjecture.lean`：將短半徑界寫成精確的全稱命題，證明對每個 C≤128 該命題不成立；由 Luna 子代理完成並經主代理整合核驗。

固定篩界 z、M 為所用篩素數的乘積時，一旦 p≥z+M，所有單位剩餘類已在 (z,p] 有整數代表。因此，僅靠有限區間的整除性放寬，最終不能優於相同模數的完整剩餘類模型。此結論沒有斷言代表元為素數，也沒有斷言所有阻斷證書會失效。

這些一般結論已在本目錄獨立編譯。`Checks.lean` 列出公理依賴，僅有 Lean/mathlib 的標準三公理之子集；沒有新增 Goldbach、Chen、Liouville、RH 或素數分布公理，也沒有 `sorry`。實際檢查輸出見 `verification.json`。

## 執行方式

在本目錄的 WSL 執行：

```sh
lake build
lake env lean Checks.lean
/usr/bin/python3.11 research/GBR53/verify.py
/usr/bin/python3.11 verify_project.py
```

Lean 版本為 `leanprover/lean4:v4.34.0-rc1`。沿用相鄰 `../mathlib4`，其套件快取亦由相鄰 mathlib 目錄提供，避免重複下載。這是本機工作區配置，搬移專案時需保留或調整該路徑。

## 舊專案如何參考

`../Goldbach-Liouville-Chen-Bridge` 為參考來源。已核對其 `Specification.lean` 的 Goldbach 定義，以及素數次序歸納和保留加數的反例審查。新目錄的 Goldbach 定義僅將同一和式等號方向反轉，意義相同；新專案沒有把舊專案的分析假設或未完成證明引入為公理。

只把與本目標的支持、量詞和見證一致的結論移植過來。尤其 Chen 的 prime+P₂ 與 Liouville 符號見證不能拼成同一組 prime+prime 見證；舊專案的有限閉包結論也不直接解決本目錄的錨點覆蓋。

## GB-R54：新的研究紀錄

`research/GBR54/REPORT.md` 給出多個禁止剩餘類的整數區間計數界，以及比完整週期條件有時更小的顯式實現門檻。單類誤差已形式化，多模數組裝為完整紙面證明；結論保證通篩整數，沒有保證素數。

另對 p≤100000 的全部 8,367 個相關區間搜尋所有並列最大單錨點貪心分支，158,400 個狀態未發現四覆蓋失敗；獨立重算其中 255 個區間。這仍是有限結果，不再僅因沒有反例就自動提高上限。搜尋需要 Python≥3.10，本機請明確使用 `/usr/bin/python3.11`。

下一道實質證明義務仍是：找到對相關可達前沿族成立、保留實際素數資訊的統一容量差，或另一個能提供實際素數出口的非循環機制。形式化條件橋樑和擴大成功樣本都不能替代這項義務。

## GB-R55：原始 δ 目標的來源核對

後續以原始區間 Goldbach 存在性為主，τ≤k 保留為可選的較強輔助目標。`research/GBR55/REPORT.md` 核對早期 `Delta` 及 `delta_scan_for_p_k` 來源：歷史掃描的約 190 萬行資料只檢查中心 p+k，並非其餘非中央項；所有相鄰端點的中央最小偏移恰為 k，而非中央偏移必大於 k。全部歷史 CSV 已由新的完整素數表逐行核對，原始參考檔案未修改。這些早期檔案不能充作 k=2 非中央存在性的全稱證明。

## GB-R56：非中央最小偏移

`research/GBR56/REPORT.md` 補上正確目標的最小偏移基線：p≤100000 的 80,818 個非中央目標由兩套算法完整重算。六個 Lean 真因子證書排除 δ≤Ck、C≤128 的短半徑輔助界；這不等於否定所有固定 C，也不等於新的 Goldbach 存在性證明。不因本次無反例而自動提高掃描上限。
